# REWEAR — More Ways To Wear

> You don't need more clothes. You just need more ways to wear them.

REWEAR is an interactive fashion styling website created for the **SIERA Showcase 2026**.

The project focuses on encouraging people to rethink the clothes they already own instead of constantly buying new ones. It allows users to explore different ways of styling individual clothing pieces and discover how small changes in styling can completely transform an outfit.

---

## Project Overview

REWEAR explores the idea that a wardrobe doesn't have to be bigger to feel new.

Through interactive styling experiences, users can:

- Explore different styling directions for individual clothing pieces
- Experiment with different fashion aesthetics
- Style outfits based on occasions and personal energy
- Discover their personal "Style DNA"
- Reinterpret existing wardrobe pieces in new ways

The goal is to make fashion feel more **creative, personal and sustainable**.

---

## Featured Styling Experience

### One Piece. Many Ways.

The main styling section allows users to select a clothing piece and explore four different ways to wear it.

| Clothing Piece | Styling Directions |
|---|---|
| White Shirt | Minimal · Street · Feminine · Smart |
| Basic Tee | Casual · Street · Layered · Chic |
| Tank Top | Casual · Summer · Sporty · Layered |
| Tie Neck Blouse | Office · Feminine · Casual · Evening |

Each styling direction includes:

- A dedicated outfit image
- Style title
- Styling description
- Practical style tip

---

## Interactive Features

### 1. One Piece. Many Ways.

Explore multiple styling possibilities for the same clothing item.

### 2. Style Without Rules

An experimental section encouraging users to:

- Break traditional styling rules
- Change the mood of an outfit
- Experiment with unexpected combinations

### 3. Style Me

An interactive three-step styling experience.

Users choose:

1. **What they're working with**
2. **Where they're going**
3. **Their desired energy**

The website then generates a personalised styling result.

### 4. Style DNA

Users answer three questions about:

- Silhouette
- Colour preferences
- Desired feeling

The experience generates a personalised style identity and visual style breakdown.

## Design Direction

REWEAR follows a minimal editorial fashion aesthetic.

### Visual Style

- Monochrome colour palette
- Editorial typography
- Minimal layouts
- Large fashion imagery
- Subtle animations
- Clean spacing and typography
- Interactive hover states

The design was intentionally kept understated so that the **clothing and styling ideas remain the visual focus**.
